# 🚀 Kanban Task Manager

A modern **Task Management Web Application** built using React, TypeScript, and Tailwind CSS.  
This application helps users efficiently manage tasks using drag-and-drop functionality with a clean and responsive UI.

---

## 🌐 Live Demo
https://kanban-task-priyanka.vercel.app/
---

## 📌 Features

- ✅ Add Tasks with custom names
- ✏️ Edit Tasks (double-click)
- ❌ Delete Tasks
- 🔄 Drag & Drop between columns (Todo, In-Progress, Completed)
- 🎯 Priority System (Low, Medium, High)
- 🔍 Search & Filter Tasks
- 📊 Dashboard (Total, Completed, Pending)
- 🌙 Dark Mode Toggle
- 💾 Data persistence using localStorage

---

## 🛠️ Libraries & Tools Used

- ⚛️ React (Vite) – Frontend framework
- 🟦 TypeScript – Type safety
- 🎨 Tailwind CSS – Styling and responsive design
- 🧠 Zustand – Lightweight state management
- 🎯 @dnd-kit/core – Drag and drop functionality
- ☁️ Vercel – Deployment platform
